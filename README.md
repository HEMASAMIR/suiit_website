## ✨ عن المشروع

**RAYA — رايا** متجر أونلاين لبراند ملابس مصري: **رجالي • أطفالي • جملة**. مبني بـ **Next.js 16** بواجهة عربية كاملة (RTL)، بألوان (نيفي `#0e2c4e` • تيل `#0d9488` • دهبي `#f59e0b`)، ووضع **لايت / دارك**، وأنيميشن ثلاثي الأبعاد في كل حتة — من غير ما يبقى أوفر — ولوحة تحكم كاملة للأدمن فيها **CRUD على كل حاجة + حساب الأرباح**.

## 🚀 التشغيل

</div>

```bash
npm install
npm run dev                  # http://localhost:3000
npm run build && npm start   # production
```

<div dir="rtl">

> على ويندوز لو PowerShell قال `running scripts is disabled` استخدم `npm.cmd run dev`.

### 🔐 لوحة التحكم

- الرابط: `/admin` (أو ادخل ببيانات الأدمن من صفحة `/login`)
- اعمل ملف `.env.local` وحط فيه بيانات الدخول (**لازم تتغير قبل النشر** — من غيرها الموقع بيستخدم بيانات افتراضية مكتوبة في الكود):

</div>

```env
ADMIN_EMAIL=you@yourstore.com
ADMIN_PASSWORD=your-strong-password
ADMIN_SECRET=a-long-random-string
```

<div dir="rtl">

### 💾 البيانات

- كل البيانات (منتجات، طلبات، شحن، كوبونات…) في `data/db.json` وبتتعمل تلقائيًا أول تشغيل من `src/lib/seed.ts`.
- الصور المرفوعة من الأدمن في `data/uploads`.
- مجلد `data` مش بيترفع على GitHub — امسحه عشان ترجع للبيانات الأصلية.
- الاستضافة لازم تكون **سيرفر Node** (VPS / Railway / Render) عشان الملفات تتحفظ.

## 🗂️ هيكل المشروع

</div>

```text
src/
├─ app/
│  ├─ (store)/          # Home, shop, product, checkout, order, track, login, register, account
│  ├─ admin/            # Login + panel (dashboard, orders, products, shipping, settings, …)
│  ├─ api/              # Orders, coupons, customer auth, admin CRUD, shipping-bulk, upload
│  └─ uploads/[file]/   # Serves admin-uploaded images
├─ components/          # Header, logo, tilt, cart, product cards, motion helpers
│  ├─ home/             # Hero, collection ring (3D), sections, showcase (wholesale, features, reviews)
│  └─ admin/            # Shell, CRUD page, dashboard, UI kit
├─ lib/                 # JSON DB, auth (HMAC cookies + scrypt passwords), orders, seed
└─ proxy.ts             # Protects /admin/*
```
